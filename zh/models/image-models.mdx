---
title: 图片模型
description: 图片生成和图片编辑模型能力。
---

图片模型可以支持以下能力中的一种或多种：

- 文生图。
- 带参考素材的图生图。
- OpenAI 兼容图片生成。
- OpenAI 兼容图片编辑。
- Gemini 兼容图片工作流。

具体支持的尺寸、参考图数量和参数范围由平台模型能力注册表定义，并展示在模型详情页中。

生产环境建议使用 `/v1/images/generations` 创建任务，并通过 `/v1/tasks/{task_id}` 查询结果。


## 可用模型

| 模型 ID | 简介 |
| --- | --- |
| `gpt-image-2` | 兼容 GPT-Image 2 的图像生成与编辑。 |
| `nano-banana-pro` | Nano Banana Pro 高保真图像生成。 |
| `nano-banana-2` | Nano Banana 2 高质量图像生成。 |
| `nano-banana` | Nano Banana 图像生成，具备稳定的供应商路由。 |
| `z-image` | 快速 Z-Image 生成，具备稳定的供应商路由。 |
| `seedance-5.0` | 通过火山方舟（Volcengine Ark）的 Seedance 5.0 图像生成。 |

---
title: 图片模型
description: 图片生成和图片编辑模型能力。
---

图片模型可以支持以下能力中的一种或多种：

- 文生图。
- 带参考素材的图生图。
- OpenAI 兼容图片生成。
- OpenAI 兼容图片编辑。
- Gemini 兼容图片工作流。

具体支持的尺寸、参考图数量和参数范围由平台模型能力注册表定义，并展示在模型详情页中。

生产环境建议使用 `/v1/images/generations` 创建任务，并通过 `/v1/tasks/{task_id}` 查询结果。


## 可用模型

| 模型 ID | 简介 |
| --- | --- |
| `gpt-image-2` | 支持 `auto`、正整数 `size` 目标或比例简写，并映射到最接近的官方常用尺寸；同时支持 `low` / `medium` / `high` 质量控制。 |
| `gpt-image-2.5` | 固定使用 Flare 语义的默认别名，支持六档质量、1K/2K/4K、参考图、蒙版和透明背景。 |
| `gpt-image-2.5-flare` | 显式低延迟 Flare 路线，适合日常图片生成与编辑。 |
| `gpt-image-2.5-sunburst` | 精细 Sunburst 路线，适合复杂生成、局部编辑、文字排版与多参考图工作流。 |
| `nano-banana-pro` | Nano Banana Pro 高保真图像生成。 |
| `nano-banana-2` | Nano Banana 2 高质量图像生成。 |
| `nano-banana` | Nano Banana 图像生成，适合稳定的生产调用。 |
| `z-image` | 快速 Z-Image 生成，适合低延迟图片任务。 |
| `seedance-5.0` | 通过火山方舟（Volcengine Ark）的 Seedance 5.0 图像生成。 |

图片模型可以支持以下能力中的一种或多种：

- 文生图。
- 带参考素材的图生图。
- OpenAI 兼容图片生成。
- OpenAI 兼容图片编辑。
- Gemini 兼容图片工作流。

具体支持的尺寸、参考图数量和参数范围由平台模型能力注册表定义，并展示在模型详情页中。

生产环境建议使用 `/v1/images/generations` 创建任务，并通过 `/v1/tasks/{task_id}` 查询结果。


## 可用模型

| 模型 ID | 简介 |
| --- | --- |
| `gpt-image-2` | 支持 `auto`、正整数 `size` 目标或比例简写，并映射到最接近的官方常用尺寸；同时支持 `low` / `medium` / `high` 质量控制。 |
| `gpt-image-2.5` | 固定使用 Flare 语义的默认别名，支持六档质量、1K/2K/4K、参考图、蒙版和透明背景。 |

## GPT Image 2.6 — PNG 与 GIF 动图

使用公开模型 ID `gpt-image-2.6` 请求 PNG 静态图或可下载的 GIF 动图。每次成功请求返回一个结果，两种格式均为 **30 积分**。调用前请在 `GET /v1/models` 确认模型是否可用；文档示例不代表当前已启用。

### 支持的请求参数

- `output_format`：`png`（默认）或 `gif`。
- `quality`：仅 `auto`。`resolution`：仅 `1K`。`n`：仅 `1`。
- `size`：`auto`、`1:1`、`3:2`、`2:3`、`1024x1024`、`1536x1024` 或 `1024x1536`。
- `image_urls`：最多一张参考图。这是 APIAny.AI 当前对本模型的限制；纯文生图时不传。

GIF 的实际像素尺寸、帧数和帧间隔可能变化，不能配置。请勿发送 `frame_count` 或 `frame_duration_ms`。不支持 SVG、JPEG、WebP、2K/4K、蒙版和输出压缩。`background` 仅兼容 `auto`，可直接省略。不支持的值（包括 SVG）返回 HTTP `400`，不会把 SVG 请求静默改为 PNG。

顶层及 `model_params` 中的兼容别名也受相同限制，冲突值返回 HTTP `400`。建议使用下方规范字段，不保证任意模型参数都可用。

### 创建 PNG 任务

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A polished studio photograph of an orange ceramic robot","output_format":"png","size":"1:1","n":1}'
```

### 创建 GIF 任务

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A friendly orange robot waving in a smooth loop","output_format":"gif","size":"1:1","n":1}'
```

### 轮询并下载

生成接口返回 HTTP `202`、`task_id` 和 `poll_url`。状态为 `pending` 或 `processing` 时继续查询，达到 `completed` 或 `failed` 后停止。处理中不要重复提交同一任务。

```bash
curl https://apiany.ai/v1/tasks/task_123 \
  -H "Authorization: Bearer $APIANY_API_KEY"
```

`completed` 后从 `result.data[0].url` 下载文件。成功的 GIF 结果是真正的动图文件，不是视频地址或逐帧图片集。GIF 请求若得到静态图或错误格式，任务会失败，并按常规失败任务积分退款规则处理。

```json
{
  "task_id": "task_123",
  "status": "completed",
  "model": "gpt-image-2.6",
  "type": "image",
  "result": {
    "created": 1793836800,
    "data": [
      {
        "url": "https://example.com/result.gif"
      }
    ]
  },
  "error": null
}
```

`/v1/images/generations/sync` 接受相同参数。HTTP `200` 时从 `data[0].url` 获取文件；HTTP `202` 表示仍在处理，需继续轮询。`/v1/images/edits` 支持 JSON 参考图地址或 multipart 上传一张参考图，同样可选 PNG/GIF，每次成功请求 30 积分。示例见图片生成指南。

## Nano Banana 2.1

用 `quality` 选择 `1K`、`2K` 或 `4K`，默认 `1K`。兼容 `img_size`、`imageSize` 和 `resolution` 别名，但不能传入互相冲突的档位。`size` 表示宽高比；图生图请求可传 `image_urls`。本模型不提供 `0.5K`、搜索或思考参数。

```bash
curl https://apiany.ai/api/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "nano-banana-2.1", "prompt": "A ceramic vase on a clean studio table, soft natural light", "quality": "1K", "size": "1:1", "n": 1}'
```

通过 `/v1/tasks/{task_id}` 查询结果。每张图片的价格为：1K 25 积分、2K 50 积分、4K 75 积分。

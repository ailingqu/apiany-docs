---
title: 视频模型
description: 视频生成模型能力。
---

视频模型默认按异步任务处理。

不同模型可能支持以下不同组合：

- 文本输入。
- 图片参考输入。
- 视频参考输入。
- 音频参考输入。
- 时长选项。
- 分辨率选项。
- 宽高比选项。

APIAny.AI 会在执行前校验公开请求参数，因此不支持的模型参数会返回清晰错误。

## 可用模型

| 模型 ID | 简介 |
| --- | --- |
| `veo3-1-quality` | Google Veo 3.1 Quality —— 高保真视频生成，带原生音频。 |
| `veo3-1-quality-4k` | Google Veo 3.1 Quality 4K —— 顶级保真 4K 视频生成，带原生音频。 |
| `veo3-1-fast` | Google Veo 3.1 Fast —— 快速文生视频，带原生音频。 |
| `veo3-1-fast-4k` | Google Veo 3.1 Fast 4K —— 快速视频生成，输出 4K 分辨率。 |
| `veo3-1-fast-ref` | Google Veo 3.1 Fast（参考图）—— 由参考图引导的快速视频生成。 |
| `veo3-1-lite` | Google Veo 3.1 Lite —— 经济档，适合高并发视频生成。 |
| `seedance-2.0-pro` | Seedance 2.0 Pro —— 高级档 Seedance 视频生成，保真度更高、时长更长。 |
| `seedance-2.0` | Seedance 2.0 —— 通过火山方舟的高质量文/图生视频。 |
| `seedance-1.5-pro` | Seedance 1.5 Pro —— 增强版 Seedance 视频生成，运动与细节更佳。 |
| `seedance-1.0` | Seedance 1.0 —— 快速、低成本的文/图生视频。 |
| `gemini-omni-t2v` | 通过 APIPod 的 Google Gemini Omni 文生视频。 |
| `gemini-omni-i2v` | 通过 APIPod 的 Google Gemini Omni 图生视频，支持 1-3 张参考图。 |
| `wan3.0-prime-text-to-video` | Wan 3.0 Prime 文生视频，支持 2-30 秒、480p/720p/1080p 与可选音频。 |
| `wan3.0-prime-image-to-video` | Wan 3.0 Prime 图生视频，使用必填首帧和可选尾帧控制画面。 |
| `wan3.0-prime-reference-video` | Wan 3.0 Prime 参考视频，支持有序图片、视频、音频以及可选文档或网页上下文。 |
| `minimax-h3-text-to-video` | MiniMax H3（Hailuo 3）文生视频，经 EvoLink 接入，4-15 秒、768p 或 2K。 |
| `minimax-h3-image-to-video` | MiniMax H3（Hailuo 3）图生视频，经 EvoLink 接入，支持首尾帧控制。 |
| `minimax-h3-reference-to-video` | MiniMax H3（Hailuo 3）参考生视频，经 EvoLink 接入，支持图/视频/音频参考。 |
| `seedance-2.5-text-to-video` | Seedance 2.5 文生视频，经 EvoLink 接入，4-30 秒、480p/720p/1080p，可用 `duration: -1` 自动时长。 |
| `seedance-2.5-image-to-video` | Seedance 2.5 图生视频，经 EvoLink 接入，支持首尾帧控制。 |
| `seedance-2.5-reference-to-video` | Seedance 2.5 参考生视频，经 EvoLink 接入，最多 30 张图、10 段视频、10 段音频。 |
| `seedance-2.5-video-edit` | Seedance 2.5 视频编辑，经 EvoLink 接入，按提示词改写已有片段。 |
| `seedance-2.5-video-extend` | Seedance 2.5 视频延长，经 EvoLink 接入，按提示词续写已有片段。 |
| `seedance-2.0-mini-text-to-video` | Seedance 2.0 Mini 文生视频，经 EvoLink 接入，4-15 秒、480p/720p 低成本草稿。 |
| `seedance-2.0-mini-image-to-video` | Seedance 2.0 Mini 图生视频，经 EvoLink 接入，支持首尾帧控制。 |
| `seedance-2.0-mini-reference-to-video` | Seedance 2.0 Mini 参考生视频，经 EvoLink 接入，支持图/视频/音频参考。 |

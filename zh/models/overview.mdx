---

APIAny.AI 对外暴露公开模型 ID。这些 ID 是应用集成时使用的稳定产品契约。

当前公开模型家族包括：

- 图片生成模型，例如 Z-Image、Nano Banana、GPT Image、Seedance 图片模型。
- 视频生成模型，例如 Seedance、Veo、Wan、Gemini Omni。
- 对话模型，例如 Gemini、GPT、DeepSeek、MiniMax。

## 公开模型 ID

调用时使用控制台和模型页面展示的模型 ID：

```json
{
  "model": "gpt-5.4"
}
```

## 模型调用

在 API 请求中使用公开模型 ID，APIAny.AI 会返回该模型家族对应的标准响应。

## 能力元数据

`GET /v1/models` 会为每个模型返回 `capability_metadata` 对象，客户端代码可以直接读取它来配置模型，不必把假设写死：

- `input` 与 `output` 列出接受的输入类型与产生的输出类型。
- `features` 说明是否支持 `stream`、`tools`、`vision`、`jsonMode`，以及模型是否具备思考能力（`thinking`）。
- `reasoning` 描述思考控制方式：`mode`（`always-on`、`optional` 或 `none`）、支持的 `efforts`、省略 effort 时生效的 `defaultEffort`，以及可关闭思考的模型的 `disableWith`。
- `limits` 给出 `contextWindow` 与 `maxOutputTokens`。

官方模型 ID 也可作为等价 ID 调用：`deepseek-flash`（= `deepseek-v4.1-flash`）与
`deepseek-v4-pro`（= `deepseek-v4`）；`GET /v1/models` 会用 `alias_of` 标注这类条目。

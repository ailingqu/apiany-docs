APIAny.AI 为开发者提供统一的 AI API 网关，用一个 API Key 接入对话、图片、视频和多模态模型。

对外调用接口保持稳定；APIAny.AI 负责模型执行、积分计费、任务记录和返回格式整理，让开发者获得一致的调用体验。

## 公开 API 形态

APIAny.AI 对外提供少量稳定的调用模式：

- 对话：`/v1/chat/completions`
- Anthropic 兼容 Messages：`/v1/messages`
- Gemini 兼容内容生成：`/v1beta/models/{model}:generateContent`
- 图片生成：`/v1/images/generations`
- 视频生成：`/v1/videos/generations`
- 任务查询：`/v1/tasks/{task_id}`

媒体生成默认推荐使用异步接口。同步等待接口适合调试和简单集成，生产环境建议创建任务后通过 task ID 轮询结果。

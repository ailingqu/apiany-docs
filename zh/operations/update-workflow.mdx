---
title: 文档更新流程
description: 如何让 APIAny.AI 文档和平台能力保持同步。
---

文档仓库应与应用仓库保持解耦。

## 常规更新流程

1. 在平台仓库中更新接口、模型能力或公开行为。
2. 如果公开 API 发生变化，同步更新 `openapi.json` 和 `zh/openapi.json`。
3. 更新相关英文和中文 MDX 指南。
4. 执行 `pnpm validate`。
5. 提交并推送，Mintlify 自动发布。

## 后续自动同步

平台可以提供一个文档导出命令，输出：

- 公开模型目录 JSON。
- OpenAPI endpoint 定义。
- 价格表数据。
- 模型能力字段元数据。

文档仓库通过 `scripts/sync-from-platform.mjs` 消费这些导出数据，从而保持运行时应用和文档站点解耦。

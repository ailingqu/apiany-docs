---
title: 错误处理
description: APIAny.AI 标准错误分类。
---

APIAny.AI 会在所有支持的模型 API 中返回一致的错误结构。

```json
{
  "error": {
    "type": "rate_limit",
    "message": "Rate limit exceeded"
  }
}
```

## 错误分类

- `invalid_request`
- `auth_error`
- `rate_limit`
- `insufficient_quota`
- `content_policy`
- `timeout`
- `network_error`
- `service_error`
- `billable_error`
- `unknown`

公开响应只包含开发者排查问题所需的信息。

---
title: 任务查询
description: 查询图片、视频以及后续音频等异步任务状态。
---

使用 `/v1/tasks/{task_id}` 查询异步任务状态。

```bash
curl https://api.apiany.ai/v1/tasks/task_123 \
  -H "Authorization: Bearer $APIANY_API_KEY"
```

## 状态值

- `pending`
- `processing`
- `completed`
- `failed`
- `expired`

## 成功任务

```json
{
  "task_id": "task_123",
  "status": "completed",
  "model": "nano-banana",
  "result": {
    "type": "image",
    "urls": ["https://.../result.png"]
  }
}
```

## 失败任务

```json
{
  "task_id": "task_123",
  "status": "failed",
  "error": {
    "type": "upstream_5xx",
    "message": "The upstream provider could not complete the request."
  }
}
```

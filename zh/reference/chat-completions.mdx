---
title: Chat Completions
description: OpenAI 兼容的对话生成接口。
---

使用 `/v1/chat/completions` 调用 OpenAI 兼容的对话生成接口。

```bash
curl https://api.apiany.ai/v1/chat/completions \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "messages": [
      { "role": "system", "content": "You are concise." },
      { "role": "user", "content": "用一句话解释什么是 API 聚合。" }
    ],
    "temperature": 0.7
  }'
```

## 流式

设置 `stream: true` 即可通过 SSE 流式返回。每个事件是 OpenAI
`chat.completion.chunk`，流以 `data: [DONE]` 结束。

```bash
curl https://api.apiany.ai/v1/chat/completions \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -N \
  -d '{
    "model": "gpt-5.4",
    "messages": [{ "role": "user", "content": "你好" }],
    "stream": true
  }'
```

## 参数

支持 OpenAI 标准参数：`temperature`、`top_p`、`max_tokens`、`stop`、`n`、
`frequency_penalty`、`presence_penalty`、`seed`、`response_format`、`tools`、
`tool_choice`、`logprobs`、`top_logprobs`、`logit_bias`、`user`、`stream`。

## 说明

- `model` 是 APIAny.AI 的公开模型 ID，不是供应商侧的部署 ID。
- 如果模型响应包含 token usage，平台会尽量归一化到 OpenAI 风格的 `usage` 对象。

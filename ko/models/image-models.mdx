이미지 모델은 다음 기능 중 하나 이상을 지원할 수 있습니다:

- 텍스트 투 이미지.
- 참조 에셋을 사용한 이미지 투 이미지.
- OpenAI 호환 이미지 생성.
- OpenAI 호환 이미지 편집.
- Gemini 호환 이미지 워크플로.

지원되는 구체적인 크기, 이미지 사이즈 지원, 참조 이미지 개수 제한은 플랫폼 모델 능력 레지스트리에서 정의되며 모델 상세 페이지에 반영됩니다.

프로덕션 통합에서는 `/v1/images/generations`로 작업을 생성하고 `/v1/tasks/{task_id}`로 결과를 폴링하는 것을 권장합니다.

## GPT Image 2.6 — PNG 및 애니메이션 GIF

공개 모델 ID `gpt-image-2.6`으로 PNG 정지 이미지 또는 다운로드 가능한 애니메이션 GIF를 요청하세요. 성공한 요청은 결과 하나를 반환하며 두 형식 모두 **30크레딧**입니다. 사용 전에 `GET /v1/models`에서 사용 가능 여부를 확인하세요. 예제는 현재 활성화를 보장하지 않습니다.

### 지원 요청 매개변수

- `output_format`: `png`(기본값) 또는 `gif`.
- `quality`: `auto`만 지원. `resolution`: `1K`만 지원. `n`: `1`만 지원.
- `size`: `auto`, `1:1`, `3:2`, `2:3`, `1024x1024`, `1536x1024`, `1024x1536`.
- `image_urls`: 참조 이미지 최대 한 장. APIAny.AI에서 이 모델에 적용하는 현재 제한입니다. 텍스트만으로 생성할 때는 생략하세요.

GIF의 실제 픽셀 크기, 프레임 수와 간격은 달라질 수 있으며 설정할 수 없습니다. `frame_count` 또는 `frame_duration_ms`를 보내지 마세요. SVG, JPEG, WebP, 2K/4K, 마스크 및 출력 압축은 지원하지 않습니다. `background`는 호환용 `auto`만 허용하며 생략할 수 있습니다. SVG를 포함한 미지원 값은 HTTP `400`을 반환하며 SVG를 PNG로 자동 대체하지 않습니다.

최상위와 `model_params` 안의 호환 별칭에도 같은 제한이 적용됩니다. 충돌하는 값은 HTTP `400`을 반환합니다. 아래의 표준 필드를 사용하세요. 임의의 모델 매개변수 지원은 보장하지 않습니다.

### PNG 작업 만들기

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A polished studio photograph of an orange ceramic robot","output_format":"png","size":"1:1","n":1}'
```

### GIF 작업 만들기

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A friendly orange robot waving in a smooth loop","output_format":"gif","size":"1:1","n":1}'
```

### 폴링 및 다운로드

생성 엔드포인트는 HTTP `202`, `task_id`, `poll_url`을 반환합니다. 상태가 `pending` 또는 `processing`이면 계속 폴링하고, `completed` 또는 `failed`이면 중단하세요. 처리 중인 작업을 중복 제출하지 마세요.

```bash
curl https://apiany.ai/v1/tasks/task_123 \
  -H "Authorization: Bearer $APIANY_API_KEY"
```

`completed` 후 `result.data[0].url`에서 파일을 다운로드하세요. 성공한 GIF는 실제 애니메이션 파일이며 동영상 URL이나 프레임 모음이 아닙니다. GIF 요청에 정지 이미지 또는 잘못된 형식이 반환되면 작업이 실패하고 일반 실패 작업 크레딧 환불 정책을 따릅니다.

```json
{
  "task_id": "task_123",
  "status": "completed",
  "model": "gpt-image-2.6",
  "type": "image",
  "result": {
    "created": 1793836800,
    "data": [
      {
        "url": "https://example.com/result.gif"
      }
    ]
  },
  "error": null
}
```

`/v1/images/generations/sync`는 같은 매개변수를 받습니다. HTTP `200`은 `data[0].url`에 파일 URL을 반환하고, HTTP `202`이면 계속 폴링해야 합니다. `/v1/images/edits`는 JSON 또는 multipart로 참조 이미지 한 장을 받으며 PNG/GIF 선택과 성공 요청당 30크레딧 요금이 동일합니다. 이미지 생성 가이드에서 예제를 확인하세요.

## Nano Banana 2.1

`quality`를 `1K`, `2K` 또는 `4K`로 설정합니다. 기본값은 `1K`입니다. `img_size`, `imageSize`, `resolution` 별칭도 지원하지만 서로 충돌하는 값을 지정하면 안 됩니다. `size`는 화면 비율이며, 참조 이미지 편집에는 `image_urls`를 사용합니다. `0.5K`, 검색 및 추론 매개변수는 제공하지 않습니다.

```bash
curl https://apiany.ai/api/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "nano-banana-2.1", "prompt": "A ceramic vase on a clean studio table, soft natural light", "quality": "1K", "size": "1:1", "n": 1}'
```

`/v1/tasks/{task_id}`에서 결과를 조회합니다. 이미지당 가격은 1K 25크레딧, 2K 50크레딧, 4K 75크레딧입니다.

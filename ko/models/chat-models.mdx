채팅 모델은 다음 인터페이스를 통해 제공될 수 있습니다:

- `/v1/chat/completions`
- `/v1/messages`
- `/v1beta/models/{model}:generateContent`

가격에는 다음이 포함될 수 있습니다:

- 입력 token.
- 출력 token.
- 캐시된 입력 token.
- 최소 요청 크레딧.

컨텍스트 윈도우와 최대 출력 길이는 모델 수준의 능력 메타데이터입니다.

## 추론 강도

Chat Completions에서는 `reasoning_effort`, Responses에서는 `reasoning: { "effort": "high" }`를 사용합니다. 각 엔드포인트는 다른 형식도 호환 별칭으로 받습니다. 둘 다 지정하면 값이 같아야 하며, 충돌 시 `400`을 반환합니다. 생략하면 기존 모델 기본 동작을 유지합니다.

문법상 허용 값은 `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`입니다. 모든 모델이 모든 값을 지원한다는 뜻은 아닙니다. 잘못된 값이나 지원 범위가 명시된 모델의 미지원 값은 `400`을 반환합니다.

| 모델 | 지원 effort |
| --- | --- |
| Kimi K3 | `max` |
| GPT-5.4 / GPT-5.5 | `none`, `low`, `medium`, `high`, `xhigh` |
| GPT-5.4 Pro / GPT-5.5 Pro | `medium`, `high`, `xhigh` |
| Claude Opus 4.7 / 4.8 | `low`, `medium`, `high`, `xhigh`, `max` |
| Claude Opus 4.6 / Sonnet 4.6 | `low`, `medium`, `high`, `max` |
| Claude Opus 4.5 | `low`, `medium`, `high` |
| Gemini 3 | 지원 수준은 모델별로 다름. `none` 미지원 |
| Gemini 2.5 | `none`, `minimal`, `low`, `medium`, `high`. Pro는 `none` 미지원 |

Anthropic Messages에서는 `output_config.effort`를 사용합니다. 네이티브 `thinking`은 독립적이며, effort는 추론을 켜거나 `budget_tokens`를 설정하지 않습니다.

Gemini 3 네이티브 요청은 `generationConfig.thinkingConfig.thinkingLevel`을 사용하며 지원 수준은 모델별로 다릅니다. Gemini 2.5는 `thinkingBudget`을 사용합니다. OpenAI 호환 형식에서 Gemini 2.5의 `minimal`/`low`는 `1024`, `medium`은 `8192`, `high`는 `24576`, `none`은 `0`(Pro 제외)으로 매핑됩니다. 명시적인 effort와 네이티브 `thinkingLevel` 또는 `thinkingBudget`은 동시에 지정할 수 없으며, 설정이 동등해도 `400`을 반환합니다. `includeThoughts`만 있으면 effort와 함께 사용할 수 있습니다.

다른 OpenAI 호환 모델에도 문법상 유효한 effort를 제출할 수 있지만 모델 지원을 보장하지는 않습니다. 특정 값에 의존하기 전에 모델 기능을 확인하세요.

`max_completion_tokens`, `max_output_tokens` 및 네이티브 대응 필드는 추론과 최종 답변 토큰의 합계를 제한합니다. effort 자체는 출력 토큰 상한이 아닙니다. 예산이 소진되면(Chat Completions의 `finish_reason: "length"`) 최종 답변이 불완전하거나 비어 있을 수 있습니다.

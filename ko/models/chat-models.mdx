---
title: 채팅 모델
description: 텍스트 생성 및 멀티모달 채팅 모델 동작.
---

채팅 모델은 다음 인터페이스를 통해 제공될 수 있습니다:

- `/v1/chat/completions`
- `/v1/messages`
- `/v1beta/models/{model}:generateContent`

가격에는 다음이 포함될 수 있습니다:

- 입력 token.
- 출력 token.
- 캐시된 입력 token.
- 최소 요청 크레딧.

컨텍스트 윈도우와 최대 출력 길이는 모델 수준의 능력 메타데이터입니다.

## 이미지

`grok-imagine-image`는 요청당 이미지 한 장을 생성합니다(`n: 1`). 텍스트만 보내면 이미지 생성, `image_urls`에 공개 HTTPS 이미지 URL 한 개를 보내면 이미지 편집입니다. 기존 이미지 편집 엔드포인트도 유지됩니다. 초기 버전에서는 마스크, 여러 참조 이미지, 사용자 지정 픽셀 크기 및 품질 단계를 지원하지 않습니다.

이미지 `size` / `aspect_ratio`: `1:1`(기본), `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`.

`POST /v1/images/generations` · `POST /v1/images/generations/sync` · `POST /v1/images/edits`

```json
{
  "model": "grok-imagine-image",
  "prompt": "연한 회색 배경 위의 빨간 도자기 머그잔. 글자 없음.",
  "size": "1:1",
  "n": 1
}
```

```json
{
  "model": "grok-imagine-image",
  "prompt": "연한 회색 배경 위의 빨간 도자기 머그잔. 글자 없음.",
  "size": "1:1",
  "n": 1,
  "image_urls": [
    "https://assets.example/reference.jpg"
  ]
}
```

## 동영상

`grok-imagine-video-1.5`의 `duration`은 정수 1~15초(기본 8초), `resolution`은 `480p`(기본), `720p`, `1080p`입니다. 참조 이미지는 최대 한 장입니다. `image_urls`를 생략하면 텍스트로 동영상을 생성합니다. 이미지 기반 동영상은 입력 이미지 비율을 따르며 `aspect_ratio`로 변경되지 않습니다.

텍스트 기반 동영상 비율: `16:9`(기본), `1:1`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`, `21:9`, `5:2`. 동영상 편집, 여러 참조, 시작·종료 프레임, 사용자 지정 오디오 입력은 초기 버전에 포함되지 않습니다.

`POST /v1/videos/generations` · `POST /v1/videos/generations/sync`

```json
{
  "model": "grok-imagine-video-1.5",
  "prompt": "회색 탁자 위 머그잔 주위를 천천히 도는 카메라. 글자 없음.",
  "duration": 1,
  "resolution": "480p",
  "aspect_ratio": "16:9"
}
```

```json
{
  "model": "grok-imagine-video-1.5",
  "prompt": "회색 탁자 위 머그잔 주위를 천천히 도는 카메라. 글자 없음.",
  "duration": 1,
  "resolution": "480p",
  "aspect_ratio": "16:9",
  "image_urls": [
    "https://assets.example/reference.jpg"
  ]
}
```

## 크레딧

이미지 생성은 60크레딧, 편집은 66크레딧입니다. 동영상은 길이 × 아래 해상도 단가로 계산하며 이미지 기반 생성은 요청당 30크레딧을 추가합니다. 기존 충전 패키지 할인은 유지됩니다.

| 해상도 | 초당 크레딧 |
| --- | ---: |
| 480p | 240 |
| 720p | 420 |
| 1080p | 750 |

## 결과 및 오류

비동기 생성 시 HTTP 202와 `task_id`, `poll_url`이 반환됩니다. 동기 방식과 이미지 편집은 완료 시 HTTP 200, 처리 중이면 HTTP 202를 반환합니다. `/v1/tasks/{task_id}`를 `completed` 또는 `failed`까지 조회한 뒤 결과 URL을 사용하세요. 대기 중인 작업은 실패가 아닙니다. 파라미터는 크레딧 예약 전에 검증됩니다. 안전 정책 거절은 실패로 처리되므로 동일한 요청을 반복 제출하지 마세요. 동기 방식은 대기 시간 초과 시 아직 완료되지 않은 작업을 반환할 수 있습니다.

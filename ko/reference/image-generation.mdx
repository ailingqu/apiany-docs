프로덕션 이미지 생성에는 `/v1/images/generations`를 사용하세요.

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nano-banana",
    "prompt": "A bright API dashboard rendered as a product hero image",
    "size": "1k"
  }'
```

응답은 task를 반환합니다.

```json
{
  "task_id": "task_123",
  "status": "processing",
  "poll_url": "/v1/tasks/task_123"
}
```

## 동기 변형

`/v1/images/generations/sync`는 task를 생성하고 설정된 최대 대기 시간까지 기다립니다.

호환성 확보와 데모 용도로 사용하세요. 프로덕션 워크로드에는 비동기 엔드포인트를 사용하세요.

## 이미지 편집

`/v1/images/edits`는 선택한 모델이 참조 이미지를 지원하는 경우 OpenAI 스타일의 이미지 편집 워크플로를 지원합니다.

## GPT Image 2.5 품질과 라우팅

`gpt-image-2.5`는 Flare로 고정된 별칭이며 정밀 편집에는 `gpt-image-2.5-sunburst`를 사용합니다. `quality`의 `auto/low/medium/high/xhigh/max`와 `resolution`의 `1K/2K/4K`는 독립적입니다. 명시적 픽셀 크기는 해상도 단계와 일치해야 하며, APIAny는 필드를 버리지 않고 호환 경로만 비용순으로 선택합니다.

```json
{"model":"gpt-image-2.5-flare","prompt":"제품 메인 이미지","size":"16:9","resolution":"2K","quality":"high","n":1}
```

편집은 최대 16개의 참조 이미지와 선택적 마스크를 지원합니다.

```json
{"model":"gpt-image-2.5-sunburst","prompt":"배경만 교체","image_urls":["https://example.com/product.png"],"mask_url":"https://example.com/mask.png","resolution":"2K","quality":"xhigh"}
```

## GPT Image 2.6

`gpt-image-2.6`은 기존 이미지 엔드포인트에서 PNG와 애니메이션 GIF를 요청하며 별도 GIF API는 필요하지 않습니다. 성공한 요청당 **30크레딧**이며 결과 하나를 반환합니다. 호출 전에 `GET /v1/models`에서 사용 가능 여부를 확인하세요.

`output_format: "png"`(기본값) 또는 `"gif"`, `quality: "auto"`, `resolution: "1K"`, `n: 1`을 사용하세요. `size`는 `auto`, `1:1`, `3:2`, `2:3`, `1024x1024`, `1536x1024`, `1024x1536`입니다. 참조 이미지는 최대 한 장이며 별칭과 `model_params`에도 같은 제한이 적용됩니다. 충돌 값은 HTTP `400`을 반환합니다.

SVG, JPEG, WebP, 2K/4K, 마스크, 압축, `frame_count`, `frame_duration_ms`는 지원하지 않습니다. GIF 크기, 프레임 수와 간격은 설정할 수 없습니다. `background`는 생략 가능하며 `auto`만 허용합니다. SVG 요청은 PNG 대신 HTTP `400`을 반환합니다.

### PNG 동기 대기

```bash
curl https://apiany.ai/v1/images/generations/sync \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A polished studio photograph of an orange ceramic robot","output_format":"png","size":"1:1","n":1}'
```

### 참조 이미지 한 장으로 GIF 생성

편집 엔드포인트는 JSON의 `image_urls` 한 항목 또는 multipart의 `image` 파일을 받습니다. 마스크는 추가하지 마세요. `output_format`으로 결과 형식을 선택하며 GIF 편집도 애니메이션 파일 하나를 반환합니다.

```bash
curl https://apiany.ai/v1/images/edits \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A friendly orange robot waving in a smooth loop","output_format":"gif","size":"1:1","n":1,"image_urls":["https://example.com/reference.png"]}'
```

multipart/form-data로 참조 파일 한 장을 업로드할 수도 있습니다:

```bash
curl https://apiany.ai/v1/images/edits \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -F "model=gpt-image-2.6" \
  -F "prompt=Animate the character waving in a smooth loop" \
  -F "image=@reference.png" \
  -F "output_format=gif" \
  -F "size=1:1" \
  -F "n=1"
```

동기 및 편집 엔드포인트는 완료 시 HTTP `200`과 `data[0].url`을, 대기 시 HTTP `202`, `task_id`, `poll_url`을 반환합니다. `/v1/tasks/{task_id}`를 `completed` 또는 `failed`가 될 때까지 폴링하세요. `pending` 또는 `processing`이면 같은 작업 ID를 유지하세요. 비동기 생성은 `/v1/images/generations`를 사용하며 완료 파일은 `result.data[0].url`에 있습니다. 유효하지 않거나 정적인 GIF 결과는 실패하며 일반 실패 작업 크레딧 환불 정책을 따릅니다.

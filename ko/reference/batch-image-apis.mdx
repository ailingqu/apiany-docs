title: 이미지 일괄 API
description: 유료 일괄 엔드포인트로 여러 이미지를 변환, 크기 조정, 자르기, 회전 및 분석합니다.
---

7개의 이미지 일괄 엔드포인트는 유료 계정의 API 키가 필요합니다. 제출한 일괄 작업 1건을 API 요청 1회로 계산합니다.

API는 최대 20개 파일, 총 100 MB, 파일당 30 MB를 지원합니다. 파일은 독립적으로 처리되므로 한 파일의 오류가 성공 결과를 제거하지 않습니다.

변환 엔드포인트는 `manifest.json`이 포함된 ZIP을, 분석 엔드포인트는 순서가 있는 JSON을 반환합니다. 각 이미지마다 `files` 필드를 반복해서 보내세요.

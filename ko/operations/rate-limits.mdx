---
title: 속도 제한
description: 요청 제한 및 할당량 동작.
---

APIAny.AI는 모델 요청을 실행하기 전에 API 키 검증, 모델 액세스 확인, 크레딧 확인, 속도 제한을 적용합니다.

요청이 설정된 한도를 초과하면 API는 다음을 반환합니다.

```json
{
  "error": {
    "type": "rate_limit",
    "message": "Rate limit exceeded"
  }
}
```

애플리케이션이나 환경마다 별도의 API 키를 사용하면 한도와 사용량을 쉽게 확인할 수 있습니다.

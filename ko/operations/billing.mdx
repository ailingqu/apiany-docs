description: APIAny.AI가 크레딧을 예상, 예약, 정산, 환불하는 방식.
---

APIAny.AI는 크레딧을 계정 단위 청구 단위로 사용합니다.

런타임 흐름은 다음과 같습니다.

1. 요청 실행 전에 크레딧을 예상합니다.
2. 예상 금액을 예약하거나 차감합니다.
3. APIAny.AI 모델 실행을 통해 요청을 처리합니다.
4. 완료 후 실제 사용량으로 정산합니다.
5. 청구 대상이 아닌 실패는 모델 오류 정책에 따라 환불합니다.

## 가격 유형

모델은 다음 기준으로 가격을 책정할 수 있습니다.

- 요청 단위
- 이미지 단위
- 영상 초 단위
- 입력 토큰
- 출력 토큰
- 캐시된 입력 토큰
- 최소 요청 하한

공개 모델 카탈로그에는 사용자에게 표시되는 가격이 나와 있습니다. 플랫폼 비용 및 정산 세부 정보는 호출자에게 표시되지 않습니다.

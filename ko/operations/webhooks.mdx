비동기 미디어 작업은 API 키 또는 요청에 대해 활성화된 경우 콜백 URL을 포함할 수 있습니다.

전송이 실패하면 플랫폼이 콜백을 재시도합니다.

콜백 본문은 작업 상세와 동일한 구조를 가집니다. `result`는 작업 유형에 따라
다릅니다. 이미지 결과는 `result.data[0].url`을 포함하고, 영상/오디오 결과는
`result.video_url` / `result.audio_url` (및 `result.urls[]`)을 포함합니다.

```json
{
  "task_id": "task_123",
  "status": "completed",
  "model": "seedance-2.0",
  "type": "video",
  "result": {
    "status": "completed",
    "video_url": "https://.../video.mp4",
    "urls": ["https://.../video.mp4"]
  }
}
```

## 권장 사항

고가치 워크플로에서는 webhook을 최종 결과로 간주하기 전에 항상 `/v1/tasks/{task_id}`를 통해 작업 상태를 확인하세요.

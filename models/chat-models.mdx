---
title: Chat models
description: Text generation and multimodal chat model behavior.
---

Chat models can be exposed through:

- `/v1/chat/completions`
- `/v1/messages`
- `/v1beta/models/{model}:generateContent`

Pricing can include:

- Input tokens.
- Output tokens.
- Cached input tokens.
- Minimum request credits.

Context window and maximum output limits are model-level capability metadata.

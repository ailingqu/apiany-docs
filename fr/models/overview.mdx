---
title: Catalogue de modèles
description: ID de modèles publics et familles de modèles prises en charge.
---

APIAny.AI expose des ID de modèles publics. Ces ID constituent des contrats produit stables pour votre application.

Les familles de modèles publiques actuelles comprennent :

- Des modèles de génération d'images tels que Z-Image, Nano Banana, GPT Image et les modèles d'images Seedance.
- Des modèles de génération de vidéos tels que Seedance, Veo, Wan et Gemini Omni.
- Des modèles de chat tels que Gemini, GPT, DeepSeek et MiniMax.

## ID de modèles publics

Utilisez l'ID de modèle affiché dans le tableau de bord et sur les pages de modèles :

```json
{
  "model": "gpt-5.4"
}
```

## Utilisation des modèles

Utilisez l'ID de modèle public dans les requêtes API et APIAny.AI renvoie une réponse standardisée pour cette famille de modèles.

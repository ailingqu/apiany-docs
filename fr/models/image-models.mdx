Les modèles d'images prennent en charge une ou plusieurs des capacités suivantes :

- Texte vers image.
- Image vers image avec des éléments de référence.
- Génération d'images compatible OpenAI.
- Édition d'images compatible OpenAI.
- Workflows d'images compatibles Gemini.

Les dimensions propres à chaque modèle, les tailles d'image prises en charge et les limites d'images de référence sont définies par le registre de capacités de la plateforme et reflétées dans les pages de modèles.

Pour les intégrations en production, privilégiez `/v1/images/generations` et interrogez `/v1/tasks/{task_id}`.

## GPT Image 2.6 — PNG et GIF animés

Utilisez l’identifiant public `gpt-image-2.6` pour demander une image PNG fixe ou un GIF animé téléchargeable. Chaque requête réussie renvoie un résultat et coûte **30 crédits**, quel que soit le format. Vérifiez sa disponibilité dans `GET /v1/models` avant utilisation ; les exemples ne garantissent pas son activation actuelle.

### Paramètres acceptés

- `output_format` : `png` (par défaut) ou `gif`.
- `quality` : `auto` uniquement. `resolution` : `1K` uniquement. `n` : `1` uniquement.
- `size` : `auto`, `1:1`, `3:2`, `2:3`, `1024x1024`, `1536x1024` ou `1024x1536`.
- `image_urls` : une seule image de référence. Il s’agit de la limite actuelle d’APIAny.AI pour ce modèle. Omettez ce champ pour une génération à partir de texte seul.

Les dimensions réelles du GIF, son nombre d’images et leurs intervalles peuvent varier et ne sont pas configurables. N’envoyez pas `frame_count` ou `frame_duration_ms`. SVG, JPEG, WebP, 2K/4K, les masques et la compression ne sont pas pris en charge. `background` accepte uniquement `auto` par compatibilité et peut être omis. Les valeurs non prises en charge, dont SVG, renvoient HTTP `400` ; SVG n’est pas remplacé silencieusement par PNG.

Ces limites s’appliquent aussi aux alias de compatibilité au premier niveau et dans `model_params`. Les valeurs contradictoires renvoient HTTP `400`. Préférez les champs canoniques ci-dessous ; la prise en charge de paramètres arbitraires n’est pas garantie.

### Créer une tâche PNG

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A polished studio photograph of an orange ceramic robot","output_format":"png","size":"1:1","n":1}'
```

### Créer une tâche GIF

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A friendly orange robot waving in a smooth loop","output_format":"gif","size":"1:1","n":1}'
```

### Interroger et télécharger

L’endpoint de génération renvoie HTTP `202` avec `task_id` et `poll_url`. Continuez les requêtes de suivi tant que le statut est `pending` ou `processing`, puis arrêtez sur `completed` ou `failed`. Ne soumettez pas de nouveau une tâche en cours.

```bash
curl https://apiany.ai/v1/tasks/task_123 \
  -H "Authorization: Bearer $APIANY_API_KEY"
```

Après `completed`, téléchargez le fichier depuis `result.data[0].url`. Un GIF réussi est un véritable fichier animé, pas une URL vidéo ni un ensemble d’images séparées. Un résultat statique ou au mauvais format pour une requête GIF fait échouer la tâche et suit la politique normale de remboursement des crédits pour les tâches échouées.

```json
{
  "task_id": "task_123",
  "status": "completed",
  "model": "gpt-image-2.6",
  "type": "image",
  "result": {
    "created": 1793836800,
    "data": [
      {
        "url": "https://example.com/result.gif"
      }
    ]
  },
  "error": null
}
```

`/v1/images/generations/sync` accepte les mêmes paramètres. HTTP `200` fournit l’URL du fichier dans `data[0].url` ; HTTP `202` indique qu’il faut continuer à interroger la tâche. `/v1/images/edits` accepte une référence en JSON ou en multipart, avec les mêmes choix PNG/GIF et 30 crédits par requête réussie. Voir les exemples du guide de génération d’images.

## Nano Banana 2.1

Définissez `quality` sur `1K`, `2K` ou `4K` (par défaut : `1K`). Les alias `img_size`, `imageSize` et `resolution` sont acceptés, sans valeurs contradictoires. `size` définit le format ; utilisez `image_urls` pour l’édition avec références. Les paramètres `0.5K`, de recherche et de réflexion ne sont pas disponibles.

```bash
curl https://apiany.ai/api/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "nano-banana-2.1", "prompt": "A ceramic vase on a clean studio table, soft natural light", "quality": "1K", "size": "1:1", "n": 1}'
```

Consultez le résultat via `/v1/tasks/{task_id}`. Prix par image : 25 crédits en 1K, 50 en 2K et 75 en 4K.

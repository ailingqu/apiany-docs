[Cline](https://cline.bot/) peut se connecter à APIAny.AI via une configuration compatible OpenAI. Une fois la configuration terminée, vous pouvez utiliser des modèles de chat, de raisonnement, de traduction et multimodaux depuis le même client.

## Prérequis

- Cline est installé.
- Vous avez créé une clé API dans le [tableau de bord APIAny.AI](https://apiany.ai/dashboard/api-keys).
- Vous avez choisi un ID de modèle, par exemple `gpt-5.4-mini` ou `gpt-4o-mini`.

## Valeurs de configuration

| Champ | Valeur |
| --- | --- |
| API mode | `OpenAI Compatible` |
| Base URL | `https://apiany.ai/v1` |
| API Key | Votre clé API APIAny.AI |
| Model | `gpt-5.4` |


## Configuration

1. Installez et ouvrez Cline dans VS Code.
2. Ouvrez les paramètres de Cline et choisissez OpenAI Compatible.
3. Saisissez la Base URL, la clé API et l'ID de modèle.
4. Enregistrez et demandez à Cline d'exécuter une petite tâche de codage pour vérifier la connexion.

## Modèles recommandés

| ID de modèle | Idéal pour |
| --- | --- |
| `gpt-5.5` | Meilleur premier choix pour le raisonnement complexe, le codage et les workflows de production. |
| `gpt-5.4` | Modèle généraliste puissant pour le chat avancé et les tâches d'agent. |
| `gpt-5.4-mini` | Équilibre entre vitesse, qualité et coût pour un usage quotidien. |
| `gpt-4o-mini` | Choix rapide et économique pour le chat simple, la traduction et les tâches légères. |
| `claude-sonnet-4-6` | ID de modèle compatible Claude pour la rédaction de longs textes et les workflows de codage. |
| `gemini-3.5-flash` | ID de modèle compatible Gemini pour un usage multimodal rapide. |

## Dépannage

### Erreurs 401 ou d'authentification

Assurez-vous que la clé API est copiée intégralement, sans espaces superflus, et qu'elle est activée dans le tableau de bord APIAny.AI.

### Le modèle n'apparaît pas dans l'application

Saisissez l'ID de modèle manuellement et vérifiez qu'il est disponible dans le [catalogue de modèles](/fr/models/chat-models). Certains outils ne récupèrent pas automatiquement la liste des modèles.

### Quelle Base URL utiliser ?

Les configurations compatibles OpenAI utilisent généralement `https://apiany.ai/v1` ; les configurations compatibles Claude utilisent généralement `https://apiany.ai` ; les outils demandant un endpoint complet utilisent `https://apiany.ai/v1/chat/completions`.

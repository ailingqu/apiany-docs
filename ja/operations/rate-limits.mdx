---
title: レート制限
description: リクエスト制限とクォータの挙動。
---

APIAny.AI は、モデルリクエストの実行前に API キーの検証、モデルアクセスのチェック、クレジットのチェック、レート制限を適用します。

リクエストが設定された制限を超えると、API は以下を返します:

```json
{
  "error": {
    "type": "rate_limit",
    "message": "Rate limit exceeded"
  }
}
```

制限と使用量を確認しやすくするため、アプリケーションや環境ごとに別々の API キーを使用してください。

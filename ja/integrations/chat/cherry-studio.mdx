[Cherry Studio](https://www.cherry-ai.com/) は OpenAI 互換の設定を通じて APIAny.AI に接続できます。設定が完了すると、同じクライアントから対話、推論、翻訳、マルチモーダルのモデルを利用できます。

## 事前準備

- Cherry Studio がインストール済みであること。
- [APIAny.AI ダッシュボード](https://apiany.ai/ja/dashboard/api-keys)で API キーを作成済みであること。
- 利用するモデル ID（例: `gpt-5.4-mini` または `gpt-4o-mini`）を決めていること。

## 設定値

| 項目 | 設定内容 |
| --- | --- |
| Name | `APIAny.AI` |
| API Key | あなたの APIAny.AI API キー |
| API URL | `https://apiany.ai` |
| モデル | `gpt-5.4-mini`、`gpt-4o-mini`、またはその他の利用可能なモデル |


## 設定手順

1. 設定を開いてモデルサービスの設定に移動します。
2. APIAny.AI という名前でカスタムの OpenAI 互換サービスを追加します。
3. API キーと API URL を入力します。
4. 新しいチャットで追加したモデルを選択してテストします。

## 推奨モデル

| モデル ID | 適した用途 |
| --- | --- |
| `gpt-5.5` | 複雑な推論、コーディング、本番ワークフローに最適な第一候補。 |
| `gpt-5.4` | 高度な対話やエージェントタスク向けの強力な汎用モデル。 |
| `gpt-5.4-mini` | 速度、品質、コストのバランスが良く、日常的な利用に適しています。 |
| `gpt-4o-mini` | シンプルな対話、翻訳、軽量タスクに適した、高速かつ経済的な選択肢。 |
| `claude-sonnet-4-6` | 長文の執筆やコーディングワークフロー向けの Claude 互換モデル ID。 |
| `gemini-3.5-flash` | 高速なマルチモーダル利用向けの Gemini 互換モデル ID。 |

## トラブルシューティング

### 401 または認証エラー

API キーが完全にコピーされ、前後に余分なスペースがなく、APIAny.AI ダッシュボードで有効になっていることを確認してください。

### アプリにモデルが表示されない

モデル ID を手動で入力し、[モデルカタログ](/ja/models/chat-models)で利用可能であることを確認してください。一部のツールはモデルリストを自動取得しません。

### どの Base URL を使えばよいか

OpenAI 互換の設定では通常 `https://apiany.ai/v1` を使用します。Claude 互換の設定では通常 `https://apiany.ai` を使用します。完全なエンドポイントを求めるツールでは `https://apiany.ai/v1/chat/completions` を使用します。

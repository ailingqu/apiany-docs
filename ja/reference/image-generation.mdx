本番環境では `/v1/images/generations` を使って非同期の画像タスクを作成することを推奨します。

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nano-banana",
    "prompt": "A bright API dashboard rendered as a product hero image",
    "size": "1k"
  }'
```

エンドポイントはタスク情報を返します：

```json
{
  "task_id": "task_123",
  "status": "processing",
  "poll_url": "/v1/tasks/task_123"
}
```

## 同期待機エンドポイント

`/v1/images/generations/sync` は生成結果が返るまで、または設定された最大待機時間に達するまで待機します。

このエンドポイントは OpenAI Images スタイルとの互換性確保やデバッグ用途に適しています。本番システムでは非同期エンドポイントの利用を推奨します。

## 画像編集

`/v1/images/edits` は OpenAI スタイルの画像編集に使用します。参照画像に対応したモデルのみがこのエンドポイントを呼び出せます。

## GPT Image 2.5 の品質とルーティング

`gpt-image-2.5` は Flare 固定のエイリアスです。精密編集には `gpt-image-2.5-sunburst` を指定します。`quality` は `auto/low/medium/high/xhigh/max`、`resolution` は `1K/2K/4K` で独立しており、明示ピクセルは解像度帯と一致する必要があります。未対応のパラメータを削除せず、対応ルートのみをコスト順に選択します。

```json
{"model":"gpt-image-2.5-flare","prompt":"商品メイン画像","size":"16:9","resolution":"2K","quality":"high","n":1}
```

編集では最大 16 枚の参照画像と任意のマスクを使用できます。

```json
{"model":"gpt-image-2.5-sunburst","prompt":"背景だけを変更","image_urls":["https://example.com/product.png"],"mask_url":"https://example.com/mask.png","resolution":"2K","quality":"xhigh"}
```

## GPT Image 2.6

`gpt-image-2.6` は既存の画像 API で PNG とアニメーション GIF を指定でき、専用の GIF API は不要です。成功したリクエストは **30 クレジット**で、結果を 1 個返します。呼び出し前に `GET /v1/models` で利用可能か確認してください。

`output_format: "png"`（既定）または `"gif"`、`quality: "auto"`、`resolution: "1K"`、`n: 1` を使用します。`size` は `auto`、`1:1`、`3:2`、`2:3`、`1024x1024`、`1536x1024`、`1024x1536`。参照画像は最大 1 枚です。エイリアスと `model_params` にも同じ制限があり、矛盾する値は HTTP `400` になります。

SVG、JPEG、WebP、2K/4K、マスク、圧縮、`frame_count`、`frame_duration_ms` は非対応です。GIF の寸法、フレーム数、表示間隔は設定できません。`background` は省略でき、`auto` のみ受け付けます。SVG は PNG に変更されず、HTTP `400` になります。

### PNG の同期待機

```bash
curl https://apiany.ai/v1/images/generations/sync \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A polished studio photograph of an orange ceramic robot","output_format":"png","size":"1:1","n":1}'
```

### 参照画像 1 枚で GIF を生成

編集 API は JSON の `image_urls` 1 件、または multipart の `image` ファイルを受け付けます。マスクは追加しないでください。`output_format` で結果形式を選び、GIF 編集でもアニメーションファイルを 1 個返します。

```bash
curl https://apiany.ai/v1/images/edits \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A friendly orange robot waving in a smooth loop","output_format":"gif","size":"1:1","n":1,"image_urls":["https://example.com/reference.png"]}'
```

multipart/form-data で参照画像ファイルを 1 枚アップロードすることもできます：

```bash
curl https://apiany.ai/v1/images/edits \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -F "model=gpt-image-2.6" \
  -F "prompt=Animate the character waving in a smooth loop" \
  -F "image=@reference.png" \
  -F "output_format=gif" \
  -F "size=1:1" \
  -F "n=1"
```

同期 API と編集 API は、完了時に HTTP `200` と `data[0].url`、待機中に HTTP `202` と `task_id`、`poll_url` を返します。`/v1/tasks/{task_id}` を `completed` または `failed` までポーリングし、`pending` や `processing` では同じタスク ID を使い続けます。非同期生成は `/v1/images/generations` を使い、完了ファイルは `result.data[0].url` にあります。無効または静止画の GIF 結果は失敗となり、通常の失敗タスクのクレジット返金ポリシーが適用されます。

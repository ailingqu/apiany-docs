---
title: 画像一括 API
description: 有料の一括エンドポイントで複数画像を変換、リサイズ、クロップ、回転、分析します。
---

7 つの画像一括エンドポイントは、有料アカウントの API キーが必要です。送信した 1 バッチを 1 API リクエストとして数えます。

API は最大 20 ファイル、合計 100 MB、各ファイル 30 MB までです。ファイルは個別に処理され、1 件のエラーで成功結果は削除されません。

変換系は `manifest.json` を含む ZIP、分析系は順序付き JSON を返します。各画像を繰り返し `files` フィールドで送信してください。

---
title: 動画モデル
description: 動画生成モデルの動作。
---

動画モデルはデフォルトで非同期タスクとして処理されます。

モデルによって、以下のさまざまな組み合わせをサポートします。

- テキスト入力。
- 画像参照入力。
- 動画参照入力。
- 音声参照入力。
- 再生時間の選択肢。
- 解像度の選択肢。
- アスペクト比の選択肢。

APIAny.AI は実行前に公開リクエストパラメータを検証するため、サポートされていないモデルオプションは明確なエラーを返します。

## 利用可能なモデル

| モデル ID | 概要 |
| --- | --- |
| `veo3-1-quality` | Google Veo 3.1 Quality —— ネイティブ音声付きの高忠実度な動画生成。 |
| `veo3-1-quality-4k` | Google Veo 3.1 Quality 4K —— ネイティブ音声付きの最高忠実度な 4K 動画生成。 |
| `veo3-1-fast` | Google Veo 3.1 Fast —— ネイティブ音声付きの高速テキストから動画生成。 |
| `veo3-1-fast-4k` | Google Veo 3.1 Fast 4K —— 4K 解像度で出力する高速な動画生成。 |
| `veo3-1-fast-ref` | Google Veo 3.1 Fast（参照画像）—— 参照画像で誘導する高速な動画生成。 |
| `veo3-1-lite` | Google Veo 3.1 Lite —— 経済的なティア。高ボリュームの動画生成に適しています。 |
| `seedance-2.0-pro` | Seedance 2.0 Pro —— プレミアムティアの Seedance 動画生成。より高い忠実度と長いクリップに対応。 |
| `seedance-2.0` | Seedance 2.0 —— Volcengine Ark 経由の高品質なテキスト/画像から動画生成。 |
| `seedance-1.5-pro` | Seedance 1.5 Pro —— 動きとディテールを改善した強化版 Seedance 動画生成。 |
| `seedance-1.0` | Seedance 1.0 —— 高速かつ低コストなテキスト/画像から動画生成。 |
| `gemini-omni-t2v` | APIPod 経由の Google Gemini Omni テキストから動画生成。 |
| `gemini-omni-i2v` | APIPod 経由の Google Gemini Omni 画像から動画生成。参照画像 1〜3 枚に対応。 |
| `wan3.0-prime-text-to-video` | Wan 3.0 Prime テキスト動画生成。2〜30 秒、480p・720p・1080p、任意の音声に対応。 |
| `wan3.0-prime-image-to-video` | Wan 3.0 Prime 画像動画生成。必須の開始フレームと任意の終了フレームを使用。 |
| `wan3.0-prime-reference-video` | Wan 3.0 Prime 参照動画生成。順序付き画像・動画・音声と、任意の文書または Web 情報に対応。 |

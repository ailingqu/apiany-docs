画像モデルは、以下の機能のうち 1 つ以上をサポートします。

- テキストから画像生成。
- 参照素材を用いた画像から画像生成。
- OpenAI 互換の画像生成。
- OpenAI 互換の画像編集。
- Gemini 互換の画像ワークフロー。

サポートされるサイズ、参照画像の枚数、パラメータの範囲は、プラットフォームのモデル能力レジストリで定義され、モデル詳細ページに反映されます。

本番環境の統合では `/v1/images/generations` でタスクを作成し、`/v1/tasks/{task_id}` で結果をポーリングすることを推奨します。


## 利用可能なモデル

| モデル ID | 概要 |
| --- | --- |
| `gpt-image-2` | `auto`、正の `size` 目標値、または比率の省略表記を最も近い公式の代表サイズへ変換し、`low` / `medium` / `high` 品質指定にも対応する画像生成と編集。 |
| `gpt-image-2.5` | Flare 固定の既定エイリアス。6 段階の品質、1K/2K/4K、参照画像、マスク、透明背景に対応。 |
| `gpt-image-2.5-flare` | 日常の生成と編集に適した明示的な低遅延 Flare ルート。 |
| `gpt-image-2.5-sunburst` | 複雑な生成、局所編集、文字、多参照用途向けの高精度 Sunburst ルート。 |
| `gpt-image-2.6` | PNG 静止画またはダウンロード可能なアニメーション GIF。1K、参照画像 1 枚まで、成功したリクエストごとに 30 クレジット。 |
| `nano-banana-pro` | Nano Banana Pro の高忠実度な画像生成。 |
| `nano-banana-2` | Nano Banana 2 の高品質な画像生成。 |
| `nano-banana-2.1` | テキストからの生成と参照画像の編集に対応し、1K・2K・4K と多様な縦横比を提供します。 |
| `nano-banana` | Nano Banana の画像生成。安定した本番呼び出しに適しています。 |
| `z-image` | 高速な Z-Image 生成。低レイテンシの画像タスクに適しています。 |
| `seedance-5.0` | Volcengine Ark 経由の Seedance 5.0 画像生成。 |

## GPT Image 2.6 — PNG とアニメーション GIF

公開モデル ID `gpt-image-2.6` で PNG 静止画またはダウンロード可能なアニメーション GIF をリクエストします。成功したリクエストは結果を 1 個返し、どちらの形式も **30 クレジット**です。使用前に `GET /v1/models` で利用可能か確認してください。サンプルは現在の有効化を保証しません。

### 対応パラメータ

- `output_format`：`png`（既定）または `gif`。
- `quality`：`auto` のみ。`resolution`：`1K` のみ。`n`：`1` のみ。
- `size`：`auto`、`1:1`、`3:2`、`2:3`、`1024x1024`、`1536x1024`、`1024x1536`。
- `image_urls`：参照画像は最大 1 枚。これは APIAny.AI における本モデルの現在の制限です。テキストのみの生成では省略します。

GIF の実際のピクセル寸法、フレーム数、表示間隔は変わる場合があり、設定できません。`frame_count` と `frame_duration_ms` は送信しないでください。SVG、JPEG、WebP、2K/4K、マスク、出力圧縮は非対応です。`background` は互換用の `auto` のみで、省略できます。SVG などの非対応値は HTTP `400` になり、SVG を PNG に置き換えることはありません。

トップレベルと `model_params` 内の互換エイリアスにも同じ制限が適用されます。矛盾する値は HTTP `400` になります。以下の標準フィールドを推奨します。任意のモデルパラメータへの対応は保証されません。

### PNG タスクの作成

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A polished studio photograph of an orange ceramic robot","output_format":"png","size":"1:1","n":1}'
```

### GIF タスクの作成

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A friendly orange robot waving in a smooth loop","output_format":"gif","size":"1:1","n":1}'
```

### ポーリングとダウンロード

生成 API は HTTP `202`、`task_id`、`poll_url` を返します。`pending` または `processing` の間はポーリングし、`completed` または `failed` で停止します。処理中に同じタスクを再送信しないでください。

```bash
curl https://apiany.ai/v1/tasks/task_123 \
  -H "Authorization: Bearer $APIANY_API_KEY"
```

`completed` 後、`result.data[0].url` からファイルをダウンロードします。成功した GIF は実際のアニメーションファイルであり、動画 URL や個別フレームの集合ではありません。GIF リクエストで静止画や異なる形式が返された場合はタスクが失敗し、通常の失敗タスクのクレジット返金ポリシーが適用されます。

```json
{
  "task_id": "task_123",
  "status": "completed",
  "model": "gpt-image-2.6",
  "type": "image",
  "result": {
    "created": 1793836800,
    "data": [
      {
        "url": "https://example.com/result.gif"
      }
    ]
  },
  "error": null
}
```

`/v1/images/generations/sync` は同じパラメータに対応します。HTTP `200` では `data[0].url` にファイル URL、HTTP `202` では処理中タスクが返るためポーリングを続けます。`/v1/images/edits` は JSON または multipart で参照画像を 1 枚受け取り、同じ PNG/GIF の選択肢と成功時 30 クレジットの料金が適用されます。画像生成ガイドの例を参照してください。

[同期待機と画像編集の例](/ja/reference/image-generation#gpt-image-26)

## Nano Banana 2.1

`quality` で `1K`、`2K`、`4K` を選択します。既定値は `1K` です。`img_size`、`imageSize`、`resolution` も使用できますが、矛盾する値は指定できません。`size` はアスペクト比、`image_urls` は編集用の参照画像です。`0.5K`、検索、思考パラメーターには対応していません。

```bash
curl https://apiany.ai/api/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "nano-banana-2.1", "prompt": "A ceramic vase on a clean studio table, soft natural light", "quality": "1K", "size": "1:1", "n": 1}'
```

`/v1/tasks/{task_id}` で結果を確認します。画像 1 枚の料金は 1K が 25 クレジット、2K が 50 クレジット、4K が 75 クレジットです。

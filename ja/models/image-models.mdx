---
title: 画像モデル
description: 画像生成と画像編集モデルの動作。
---

画像モデルは、以下の機能のうち 1 つ以上をサポートします。

- テキストから画像生成。
- 参照素材を用いた画像から画像生成。
- OpenAI 互換の画像生成。
- OpenAI 互換の画像編集。
- Gemini 互換の画像ワークフロー。

サポートされるサイズ、参照画像の枚数、パラメータの範囲は、プラットフォームのモデル能力レジストリで定義され、モデル詳細ページに反映されます。

本番環境の統合では `/v1/images/generations` でタスクを作成し、`/v1/tasks/{task_id}` で結果をポーリングすることを推奨します。


## 利用可能なモデル

| モデル ID | 概要 |
| --- | --- |
| `gpt-image-2` | `auto`、正の `size` 目標値、または比率の省略表記を最も近い公式の代表サイズへ変換し、`low` / `medium` / `high` 品質指定にも対応する画像生成と編集。 |
| `gpt-image-2.5` | Flare 固定の既定エイリアス。6 段階の品質、1K/2K/4K、参照画像、マスク、透明背景に対応。 |
| `gpt-image-2.5-flare` | 日常の生成と編集に適した明示的な低遅延 Flare ルート。 |
| `gpt-image-2.5-sunburst` | 複雑な生成、局所編集、文字、多参照用途向けの高精度 Sunburst ルート。 |
| `nano-banana-pro` | Nano Banana Pro の高忠実度な画像生成。 |
| `nano-banana-2` | Nano Banana 2 の高品質な画像生成。 |
| `nano-banana` | Nano Banana の画像生成。安定した本番呼び出しに適しています。 |
| `z-image` | 高速な Z-Image 生成。低レイテンシの画像タスクに適しています。 |
| `seedance-5.0` | Volcengine Ark 経由の Seedance 5.0 画像生成。 |

Los modelos de imagen admiten una o varias de estas capacidades:

- Texto a imagen.
- Imagen a imagen con activos de referencia.
- Generación de imágenes compatible con OpenAI.
- Edición de imágenes compatible con OpenAI.
- Flujos de trabajo de imagen compatibles con Gemini.

Las dimensiones específicas de cada modelo, los tamaños de imagen compatibles y los límites de imágenes de referencia los define el registro de capacidades de la plataforma y se reflejan en las páginas de modelos.

Las integraciones de producción deberían preferir `/v1/images/generations` y consultar `/v1/tasks/{task_id}`.

## GPT Image 2.6 — PNG y GIF animados

Use el ID público `gpt-image-2.6` para solicitar una imagen PNG estática o un GIF animado descargable. Cada solicitud correcta devuelve un resultado y cuesta **30 créditos** en ambos formatos. Compruebe su disponibilidad en `GET /v1/models` antes de usarlo; los ejemplos no garantizan que esté activado actualmente.

### Parámetros admitidos

- `output_format`: `png` (predeterminado) o `gif`.
- `quality`: solo `auto`. `resolution`: solo `1K`. `n`: solo `1`.
- `size`: `auto`, `1:1`, `3:2`, `2:3`, `1024x1024`, `1536x1024` o `1024x1536`.
- `image_urls`: como máximo una imagen de referencia. Es el límite actual de APIAny.AI para este modelo. Omita el campo para generar solo desde texto.

Las dimensiones reales del GIF, el número de fotogramas y sus intervalos pueden variar y no se pueden configurar. No envíe `frame_count` ni `frame_duration_ms`. No se admiten SVG, JPEG, WebP, 2K/4K, máscaras ni compresión. `background` solo acepta `auto` por compatibilidad y puede omitirse. Los valores no admitidos, incluido SVG, devuelven HTTP `400`; SVG no se sustituye silenciosamente por PNG.

Estos límites también se aplican a los alias de compatibilidad del nivel superior y de `model_params`. Los valores contradictorios devuelven HTTP `400`. Prefiera los campos canónicos mostrados; no se garantiza la admisión de parámetros arbitrarios.

### Crear una tarea PNG

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A polished studio photograph of an orange ceramic robot","output_format":"png","size":"1:1","n":1}'
```

### Crear una tarea GIF

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A friendly orange robot waving in a smooth loop","output_format":"gif","size":"1:1","n":1}'
```

### Consultar y descargar

El endpoint de generación devuelve HTTP `202` con `task_id` y `poll_url`. Siga consultando mientras el estado sea `pending` o `processing`; deténgase en `completed` o `failed`. No vuelva a enviar la misma tarea mientras se procesa.

```bash
curl https://apiany.ai/v1/tasks/task_123 \
  -H "Authorization: Bearer $APIANY_API_KEY"
```

Tras `completed`, descargue el archivo de `result.data[0].url`. Un GIF correcto es un archivo animado real, no una URL de vídeo ni un conjunto de fotogramas. Un resultado estático o de formato incorrecto para una solicitud GIF hace fallar la tarea y sigue la política normal de reembolso de créditos para tareas fallidas.

```json
{
  "task_id": "task_123",
  "status": "completed",
  "model": "gpt-image-2.6",
  "type": "image",
  "result": {
    "created": 1793836800,
    "data": [
      {
        "url": "https://example.com/result.gif"
      }
    ]
  },
  "error": null
}
```

`/v1/images/generations/sync` admite los mismos parámetros. HTTP `200` devuelve la URL del archivo en `data[0].url`; HTTP `202` indica que debe seguir consultando la tarea. `/v1/images/edits` admite una referencia en JSON o multipart, con las mismas opciones PNG/GIF y 30 créditos por solicitud correcta. Consulte los ejemplos de la guía de generación de imágenes.

## Nano Banana 2.1

Seleccione `1K`, `2K` o `4K` con `quality` (valor predeterminado: `1K`). Se aceptan los alias `img_size`, `imageSize` y `resolution`, sin valores contradictorios. `size` indica la relación de aspecto; use `image_urls` para editar con referencias. No se admiten `0.5K`, búsqueda ni parámetros de razonamiento.

```bash
curl https://apiany.ai/api/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "nano-banana-2.1", "prompt": "A ceramic vase on a clean studio table, soft natural light", "quality": "1K", "size": "1:1", "n": 1}'
```

Consulte el resultado en `/v1/tasks/{task_id}`. Precio por imagen: 25 créditos para 1K, 50 para 2K y 75 para 4K.

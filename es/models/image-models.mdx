---
title: Modelos de imagen
description: Comportamiento de los modelos de generación y edición de imágenes.
---

Los modelos de imagen admiten una o varias de estas capacidades:

- Texto a imagen.
- Imagen a imagen con activos de referencia.
- Generación de imágenes compatible con OpenAI.
- Edición de imágenes compatible con OpenAI.
- Flujos de trabajo de imagen compatibles con Gemini.

Las dimensiones específicas de cada modelo, los tamaños de imagen compatibles y los límites de imágenes de referencia los define el registro de capacidades de la plataforma y se reflejan en las páginas de modelos.

Las integraciones de producción deberían preferir `/v1/images/generations` y consultar `/v1/tasks/{task_id}`.


## Modelos disponibles

| Model ID | Descripción |
| --- | --- |
| `gpt-image-2` | Generación y edición con `auto`, objetivos `size` positivos o proporciones abreviadas, asignados al tamaño popular oficial más cercano, y calidad `low` / `medium` / `high`. |
| `gpt-image-2.5` | Alias predeterminado fijado a Flare, con seis calidades, 1K/2K/4K, referencias, máscaras y fondos transparentes. |
| `gpt-image-2.5-flare` | Ruta Flare explícita de baja latencia para generación y edición cotidianas. |
| `gpt-image-2.5-sunburst` | Ruta Sunburst precisa para generación compleja, edición local, texto y múltiples referencias. |
| `nano-banana-pro` | Generación de imágenes de alta fidelidad con Nano Banana Pro. |
| `nano-banana-2` | Generación de imágenes de alta calidad con Nano Banana 2. |
| `nano-banana` | Generación de imágenes Nano Banana para un uso de producción fiable. |
| `z-image` | Generación rápida con Z-Image para tareas de imagen de baja latencia. |
| `seedance-5.0` | Generación de imágenes Seedance 5.0 a través de Volcengine Ark. |

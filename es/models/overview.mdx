description: IDs de modelo públicos y familias de modelos compatibles.
---

APIAny.AI expone IDs de modelo públicos. Estos IDs son contratos de producto estables para tu aplicación.

Las familias de modelos públicas actuales incluyen:

- Modelos de generación de imágenes como Z-Image, Nano Banana, GPT Image y los modelos de imagen Seedance.
- Modelos de generación de video como Seedance, Veo, Wan y Gemini Omni.
- Modelos de chat como Gemini, GPT, DeepSeek y MiniMax.

## IDs de modelo públicos

Usa el ID de modelo que se muestra en el panel y en las páginas de modelos:

```json
{
  "model": "gpt-5.4"
}
```

## Uso de modelos

Usa el ID de modelo público en las solicitudes de API y APIAny.AI devuelve una respuesta estandarizada para esa familia de modelos.

## Metadatos de capacidades

`GET /v1/models` devuelve un objeto `capability_metadata` para cada modelo, para que el código cliente configure un modelo sin partir de suposiciones fijas:

- `input` y `output` listan los tipos aceptados y producidos.
- `features` informa de `stream`, `tools`, `vision`, `jsonMode` y de si el modelo razona o no (`thinking`).
- `reasoning` informa de los controles de razonamiento: `mode` (`always-on`, `optional` o `none`), los `efforts` aceptados, el `defaultEffort` que se aplica cuando se omite effort y `disableWith` para los modelos cuyo razonamiento se puede desactivar.
- `limits` informa de `contextWindow` y `maxOutputTokens`.

Los ID de modelo oficiales se aceptan como ID equivalentes de `deepseek-flash` (= `deepseek-v4.1-flash`) y `deepseek-v4-pro` (= `deepseek-v4`); `GET /v1/models` marca esas entradas con `alias_of`.

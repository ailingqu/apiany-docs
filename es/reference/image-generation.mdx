---
title: Generación de imágenes
description: Genera imágenes de forma asíncrona o con compatibilidad de espera síncrona.
---

Usa `/v1/images/generations` para la generación de imágenes en producción.

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nano-banana",
    "prompt": "A bright API dashboard rendered as a product hero image",
    "size": "1k"
  }'
```

La respuesta devuelve una tarea:

```json
{
  "task_id": "task_123",
  "status": "processing",
  "poll_url": "/v1/tasks/task_123"
}
```

## Variante síncrona

`/v1/images/generations/sync` crea una tarea y espera hasta el tiempo máximo de espera configurado.

Úsala para compatibilidad y demos. Usa el endpoint asíncrono para cargas de trabajo de producción.

## Edición de imágenes

`/v1/images/edits` admite flujos de edición de imágenes estilo OpenAI cuando el modelo seleccionado admite imágenes de referencia.

## Calidad y enrutamiento de GPT Image 2.5

`gpt-image-2.5` es un alias fijo de Flare; usa `gpt-image-2.5-sunburst` para edición precisa. `quality` (`auto/low/medium/high/xhigh/max`) y `resolution` (`1K/2K/4K`) son independientes. Los píxeles explícitos deben coincidir con la resolución y APIAny elige solo rutas compatibles ordenadas por coste sin eliminar campos.

```json
{"model":"gpt-image-2.5-flare","prompt":"Imagen principal de producto","size":"16:9","resolution":"2K","quality":"high","n":1}
```

La edición admite hasta 16 referencias y una máscara opcional.

```json
{"model":"gpt-image-2.5-sunburst","prompt":"Cambiar solo el fondo","image_urls":["https://example.com/product.png"],"mask_url":"https://example.com/mask.png","resolution":"2K","quality":"xhigh"}
```

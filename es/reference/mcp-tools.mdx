El catálogo contiene 61 operaciones de cuenta y `get_capabilities`. Solo se muestran las herramientas autorizadas; los permisos y la propiedad se comprueban en cada llamada. Empieza por la [guía rápida](/es/mcp-guide).

Salvo en `get_capabilities`, los campos siguientes van dentro de `arguments.input`. Las escrituras exigen además `arguments.idempotencyKey`: entre 1 y 191 caracteres ASCII imprimibles sin espacios. Los campos con valor predeterminado son opcionales. Respeta `page_size` y `pageSize`. Usa el esquema actual de `tools/list`.

El resultado aparece en `structuredContent` y como texto JSON en `content`. La primera ejecución devuelve la estructura siguiente. Una repetición devuelve `replayed: true` y un pequeño `receipt` con identificadores disponibles, sin el resultado completo ni el secreto de una clave.

```json
{
  "execution_id": "EXECUTION_ID",
  "replayed": false,
  "status": "completed",
  "data": {
    "balance": 100,
    "key": null
  }
}
```

`execution_pending` (409) indica que la primera llamada sigue sin resolverse. `execution_unknown` (409) o `status: unknown` indica que el efecto podría haber ocurrido. Consulta `get_execution` y después la tarea, pedido o acción. **No uses una clave nueva para saltarte estos estados.** Una ejecución MCP completada puede contener una tarea o aprobación web aún pendiente.

La recopilación de resultados del modelo se limita a **8 MiB y 300 segundos**. Si se interrumpe o supera un límite, el comprobante conserva cualquier `request_id` conocido. Revisa `get_execution` y la solicitud o tarea existente antes de actuar; no crees otra solicitud de pago ni una nueva clave de idempotencia para sustituir una llamada sin resolver. Desconectar el cliente no significa que una tarea ya aceptada se haya cancelado.

## `get_capabilities`

Lectura · `arguments: {}`

Tras inicializar, llama a `get_capabilities` con `{}` y lee `tools/list`. Devuelve `audience: user`, `ownership: self`, `scopes`, herramientas permitidas y `oauth: false`. Las demás herramientas personales usan `input`, incluso cuando no necesitan parámetros.

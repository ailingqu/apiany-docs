---
title: Errors
description: Standard error categories returned by APIAny.AI.
---

APIAny.AI normalizes provider errors before returning them to callers.

```json
{
  "error": {
    "type": "rate_limit",
    "message": "Rate limit exceeded"
  }
}
```

## Error categories

- `invalid_request`
- `auth_error`
- `rate_limit`
- `insufficient_quota`
- `content_policy`
- `timeout`
- `network_error`
- `upstream_5xx`
- `upstream_billable`
- `unknown`

Upstream channel names, secret keys, and raw provider internals are not exposed in public responses.

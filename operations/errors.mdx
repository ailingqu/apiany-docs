---
title: Errors
description: Standard error categories returned by APIAny.AI.
---

APIAny.AI returns consistent error responses across supported model APIs.

```json
{
  "error": {
    "type": "rate_limit",
    "message": "Rate limit exceeded"
  }
}
```

## Error categories

- `invalid_request`
- `auth_error`
- `rate_limit`
- `insufficient_quota`
- `content_policy`
- `timeout`
- `network_error`
- `service_error`
- `billable_error`
- `unknown`

Responses include only public error information that is useful for developers.

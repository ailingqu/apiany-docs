---
title: Documentation update workflow
description: How APIAny.AI documentation should stay in sync with the platform.
---

This documentation repository should stay independent from the application repository.

## Regular update flow

1. Update platform code, model capabilities, or public API behavior.
2. Export or manually update `openapi.json` when endpoints changed.
3. Update the related MDX guide.
4. Run `pnpm validate`.
5. Commit and let Mintlify publish the docs site.

## Future sync path

The platform can expose a documentation export command that writes:

- Public model catalog JSON.
- OpenAPI endpoint definitions.
- Pricing table data.
- Capability field metadata.

This docs repository should consume that exported data through `scripts/sync-from-platform.mjs`, keeping the runtime app and documentation site decoupled.

Die öffentlichen Endpoints von APIAny.AI verwenden API-Keys.

<AuthHeader />

## Sicherheitsmodell

API-Keys sind Projekt-Anmeldedaten. Behandeln Sie sie wie Passwörter:

- Geben Sie geheime API-Keys nicht in browserseitigem Code preis.
- Speichern Sie Keys in einem serverseitigen Secret-Manager oder einer Umgebungsvariable.
- Rotieren Sie Keys, wenn sie kompromittiert wurden.
- Verwenden Sie separate Keys für Entwicklung, Staging und Produktion.

## Beispiel

```bash
curl https://apiany.ai/v1/models \
  -H "Authorization: Bearer $APIANY_API_KEY"
```

## Fehler

Authentifizierungsfehler verwenden das Plattform-Fehlerformat:

```json
{
  "error": {
    "type": "auth_error",
    "message": "Invalid API key"
  }
}
```

## Persönliches MCP

Modell-HTTP-APIs verwenden normale `sk_`-API-Schlüssel. Für Kontoverwaltung per MCP einen separaten `mcp_user_`-Token mit Rechten und Ablaufdatum erstellen. Verbindung und Widerruf beschreibt [Persönliches MCP](/de/mcp-guide).

Bildmodelle unterstützen eine oder mehrere der folgenden Funktionen:

- Text zu Bild.
- Bild zu Bild mit Referenz-Assets.
- OpenAI-kompatible Bildgenerierung.
- OpenAI-kompatible Bildbearbeitung.
- Gemini-kompatible Bild-Workflows.

Modellspezifische Dimensionen, unterstützte Bildgrößen und Grenzwerte für Referenzbilder werden durch das Capability-Registry der Plattform definiert und auf den Modellseiten widergespiegelt.

Produktionsintegrationen sollten `/v1/images/generations` bevorzugen und `/v1/tasks/{task_id}` abfragen.

## GPT Image 2.6 — PNG und animierte GIFs

Mit der öffentlichen Modell-ID `gpt-image-2.6` fordern Sie ein PNG-Standbild oder eine herunterladbare animierte GIF-Datei an. Jede erfolgreiche Anfrage liefert ein Ergebnis und kostet in beiden Formaten **30 Credits**. Prüfen Sie vor der Nutzung die Verfügbarkeit in `GET /v1/models`; Beispiele garantieren keine aktuelle Freischaltung.

### Unterstützte Anfrageparameter

- `output_format`: `png` (Standard) oder `gif`.
- `quality`: nur `auto`. `resolution`: nur `1K`. `n`: nur `1`.
- `size`: `auto`, `1:1`, `3:2`, `2:3`, `1024x1024`, `1536x1024` oder `1024x1536`.
- `image_urls`: höchstens ein Referenzbild. Dies ist die aktuelle APIAny.AI-Grenze für dieses Modell. Für reine Textgenerierung lassen Sie das Feld weg.

Die tatsächlichen GIF-Pixelmaße, die Bildanzahl und die Bildintervalle können variieren und sind nicht konfigurierbar. Senden Sie weder `frame_count` noch `frame_duration_ms`. SVG, JPEG, WebP, 2K/4K, Masken und Ausgabekompression werden nicht unterstützt. `background` akzeptiert aus Kompatibilitätsgründen nur `auto` und kann entfallen. Nicht unterstützte Werte, einschließlich SVG, führen zu HTTP `400`; SVG wird nicht stillschweigend durch PNG ersetzt.

Diese Grenzen gelten auch für Kompatibilitätsaliase auf oberster Ebene und in `model_params`. Widersprüchliche Werte führen zu HTTP `400`. Verwenden Sie bevorzugt die unten gezeigten Standardfelder; beliebige Modellparameter werden nicht garantiert unterstützt.

### PNG-Aufgabe erstellen

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A polished studio photograph of an orange ceramic robot","output_format":"png","size":"1:1","n":1}'
```

### GIF-Aufgabe erstellen

```bash
curl https://apiany.ai/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6","prompt":"A friendly orange robot waving in a smooth loop","output_format":"gif","size":"1:1","n":1}'
```

### Abfragen und herunterladen

Der Generierungs-Endpunkt liefert HTTP `202` mit `task_id` und `poll_url`. Fragen Sie bei `pending` oder `processing` weiter ab und beenden Sie die Abfrage bei `completed` oder `failed`. Senden Sie laufende Aufgaben nicht erneut.

```bash
curl https://apiany.ai/v1/tasks/task_123 \
  -H "Authorization: Bearer $APIANY_API_KEY"
```

Nach `completed` laden Sie die Datei über `result.data[0].url` herunter. Ein erfolgreiches GIF-Ergebnis ist eine echte animierte Datei, keine Video-URL oder Sammlung einzelner Bilder. Liefert eine GIF-Anfrage ein Standbild oder ein falsches Format, schlägt die Aufgabe fehl; es gilt die normale Richtlinie zur Credit-Erstattung für fehlgeschlagene Aufgaben.

```json
{
  "task_id": "task_123",
  "status": "completed",
  "model": "gpt-image-2.6",
  "type": "image",
  "result": {
    "created": 1793836800,
    "data": [
      {
        "url": "https://example.com/result.gif"
      }
    ]
  },
  "error": null
}
```

`/v1/images/generations/sync` akzeptiert dieselben Parameter. HTTP `200` liefert die Datei-URL in `data[0].url`; bei HTTP `202` wird die Aufgabe weiter abgefragt. `/v1/images/edits` akzeptiert ein Referenzbild per JSON oder Multipart-Upload, mit denselben PNG/GIF-Optionen und 30 Credits pro erfolgreicher Anfrage. Beispiele finden Sie im Leitfaden zur Bildgenerierung.

## Nano Banana 2.1

Wählen Sie mit `quality` die Stufe `1K`, `2K` oder `4K` (Standard: `1K`). Die Aliase `img_size`, `imageSize` und `resolution` werden unterstützt, dürfen sich aber nicht widersprechen. `size` legt das Seitenverhältnis fest; `image_urls` übergibt Referenzbilder. `0.5K`, Such- und Denkparameter sind nicht verfügbar.

```bash
curl https://apiany.ai/api/v1/images/generations \
  -H "Authorization: Bearer $APIANY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "nano-banana-2.1", "prompt": "A ceramic vase on a clean studio table, soft natural light", "quality": "1K", "size": "1:1", "n": 1}'
```

Fragen Sie das Ergebnis über `/v1/tasks/{task_id}` ab. Preis je Bild: 25 Credits für 1K, 50 für 2K und 75 für 4K.

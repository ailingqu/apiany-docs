APIAny.AI stellt öffentliche Modell-IDs bereit. Diese IDs sind stabile Produktverträge für Ihre Anwendung.

Aktuelle öffentliche Modellfamilien umfassen:

- Bildgenerierungsmodelle wie Z-Image, Nano Banana, GPT Image und Seedance-Bildmodelle.
- Videogenerierungsmodelle wie Seedance, Veo, Wan und Gemini Omni.
- Chat-Modelle wie Gemini, GPT, DeepSeek und MiniMax.

## Öffentliche Modell-IDs

Verwenden Sie die im Dashboard und auf den Modellseiten angezeigte Modell-ID:

```json
{
  "model": "gpt-5.4"
}
```

## Modellnutzung

Verwenden Sie die öffentliche Modell-ID in API-Anfragen, und APIAny.AI gibt eine standardisierte Antwort für diese Modellfamilie zurück.

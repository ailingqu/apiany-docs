---
title: Tasks
description: Query long-running image, video, and future audio jobs.
---

Use `GET /v1/tasks/{task_id}` to query an asynchronous task from your account.
Save the task ID and the `request_id` returned when you submit the job.

```bash
curl https://apiany.ai/v1/tasks/task_123 \
  -H "Authorization: Bearer $APIANY_API_KEY"
```

## Status values

- `pending`
- `processing`
- `completed`
- `failed`
- `expired`

While `terminal` is `false`, keep the same task ID and wait the indicated
`retry_after_ms` before polling again. If your client reaches its own polling
deadline, save the ID and resume later. To recover a request when you did not
receive an ID, see [media timeout handling](/operations/errors).

## Completed task

The shape of `result` depends on the task type.

**Image** tasks return the OpenAI image format — the image URL is at `result.data[0].url`:

```json
{
  "task_id": "task_123",
  "status": "completed",
  "model": "gpt-image-2",
  "type": "image",
  "result": {
    "created": 1781597831,
    "data": [
      { "url": "https://s.apiany.ai/.../result.png" }
    ]
  },
  "error": null
}
```

**Video** and **audio** tasks return the primary URL at `result.video_url` / `result.audio_url`, and every output is also listed in `result.urls[]`:

```json
{
  "task_id": "task_456",
  "status": "completed",
  "model": "seedance-2.0",
  "type": "video",
  "result": {
    "status": "completed",
    "video_url": "https://s.apiany.ai/.../result.mp4",
    "urls": ["https://s.apiany.ai/.../result.mp4"]
  },
  "error": null
}
```

## Failed task

```json
{
  "task_id": "task_123",
  "request_id": "req_example",
  "status": "failed",
  "terminal": true,
  "result": null,
  "error": {
    "code": "not_found",
    "message": "Image generation did not return a valid image."
  }
}
```

The terminal task response includes `credits.reserved` and `credits.charged`.
The reserved value is the original estimate. Use the charged value to check the
final task cost, and see [billing](/operations/billing) for failure handling.

See [webhooks](/operations/webhooks) to receive task notifications.
